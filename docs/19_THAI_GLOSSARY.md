# คำศัพท์ไทยกลาง

คำที่ใช้กับข้อความไทยทั้งระบบ (ที่มา: `docs/superpowers/specs/2026-10-08-thai-copy-cleanup-design.md` ข้อ 2)

### 2.1 คำหลัก

| เรื่อง | ใช้ | เลิกใช้ |
|---|---|---|
| ที่ที่ทรัพย์สินอยู่ | **ที่ตั้ง** · เมนูข้อมูลหลัก "ที่ตั้ง" · ข้อไม่ตรง "ที่ตั้งไม่ตรง" | พื้นที่ · พื้นที่/ตำแหน่ง · Location |
| ผลตรวจที่ไม่ตรงระบบ | **รายการไม่ตรงทะเบียน** | Finding · ข้อมูลไม่ตรง (เมื่อหมายถึงรายการ) · รายการไม่ตรง (ไม่มีคำว่า ทะเบียน) |
| ดูแล้วตัดสินอนุมัติ/ปฏิเสธ | **พิจารณา** · รอพิจารณา · พิจารณาแล้ว | Review · ตรวจทาน |
| ให้ใช้ชั่วคราวแล้วต้องคืน | **ยืมใช้ชั่วคราว** · สถานะ **ถูกยืม** | เบิกใช้งานชั่วคราว · ถูกเบิก |
| ให้ใช้ถาวร | **ส่งมอบ** | — |
| เอาของออกจากคลัง | **เบิกจากคลัง** | — |
| รับของกลับ | **รับคืน** | — |
| รหัสบนตัวทรัพย์สิน | **รหัสทรัพย์สิน** | Asset Tag · Tag |
| ขอบเขตรอบตรวจ | **ขอบเขต** · **นอกขอบเขต** | Scope · นอก Scope |
| รอบตรวจ | **ตรวจนับ** | Audit |
| ประวัติการแก้ | **ประวัติการแก้ไข** | Audit Trail |
| ผู้ใช้ทรัพย์สิน | **ผู้ถือครอง** | ผู้ครอบครอง · ผู้ถือ (เขียนย่อ) |
| หมวด | **หมวดหมู่** ("ประเภท" ใช้กับชนิด เช่น ประเภทการถือครอง ประเภทรายการไม่ตรงทะเบียน) | หมวด (เขียนย่อ) |
| ทรัพย์สินออกจากบัญชี | **ตัดจำหน่าย** ("จำหน่าย/ขาย/บริจาค/ทำลาย" ใช้เมื่อเป็นวิธี) | — |
| เมนูส่งออกและนำเข้าที่หัวหน้าทะเบียนทรัพย์สิน | **ส่งออก / นำเข้า** (ส่งออกก่อน) · รายการในเมนู "ส่งออกตามตัวกรอง (N รายการ)" "ดาวน์โหลดแม่แบบ" "นำเข้าจาก Excel" | นำเข้า / ส่งออก · Export / Import · ปุ่มส่งออกและนำเข้าแยกกัน |
| ชุดตัวกรองที่ตั้งชื่อเก็บไว้ในหน้าทะเบียนทรัพย์สิน | **มุมมองที่บันทึกไว้** · ปุ่ม "บันทึกมุมมองนี้" | Saved view · ตัวกรองที่บันทึก |
| การ์ดแรกของฟอร์มเพิ่มทรัพย์สินที่รวมช่องที่ต้องกรอกก่อนบันทึก | **ข้อมูลที่ต้องกรอก** · ตัวนับ "กรอกแล้ว n จาก m ช่องที่ต้องกรอก" · ส่วนที่พับไว้ "กรอกแล้ว n จาก m ช่อง" | ข้อมูลบังคับ · Required |
| แถวท้ายฟอร์มที่บอกช่องที่ต้องกรอกที่ยังว่าง | **ยังขาด n ช่องที่ต้องกรอก · <ชื่อช่อง>** · ปุ่ม "ไปช่องแรกที่ยังขาด" | ยังไม่ครบ n ช่อง · กรอกไม่ครบ |
| แก้ค่าที่บันทึกผิดไว้ในทะเบียน (ที่ตั้ง ผู้ถือครอง แผนก) ไม่ใช่การย้ายจริง | **แก้ไขข้อมูล…** · ประวัติ "แก้ไขข้อมูลที่ตั้ง" "แก้ไขข้อมูลผู้ถือครอง" "แก้ไขข้อมูลแผนก" · ช่อง "เหตุผลที่แก้" · "เปลี่ยน…" ใช้กับการย้ายหรือเปลี่ยนผู้ถือครองจริง (ส่งมอบ รับคืน โอนย้าย) | แก้ข้อมูล (คำพูด) · "เปลี่ยน…" เมื่อหมายถึงแก้ที่บันทึกผิด |
| เปลี่ยนรหัสทรัพย์สินจริงในหน้าแก้ไข (ป้ายที่พิมพ์ไว้ยังแสดงรหัสเดิม) ไม่ใช่การแก้ข้อมูลที่บันทึกผิด | **เปลี่ยนรหัส** · ชื่อหน้าต่างและประวัติ "เปลี่ยนรหัสทรัพย์สิน" · ช่อง "รหัสใหม่" · ปุ่ม "ใช้รหัสนี้" | แก้ไขรหัส · แก้ไขข้อมูลรหัส |
| หัวการ์ดแรกของหน้าเพิ่มและหน้าแก้ไขทรัพย์สิน และปุ่มบันทึกของหน้าแก้ไข | **ข้อมูลที่ต้องกรอก** ทั้งสองหน้า (หน้าแก้ไขไม่มีตัวนับ) · ปุ่ม "บันทึกการแก้ไข" (หน้าเพิ่มใช้ "บันทึก") | ข้อมูลหลัก (เป็นชื่อเมนูข้อมูลหลัก) |
| ช่องที่แก้ในหน้าแก้ไขทรัพย์สิน ก่อนบันทึก | **แก้แล้ว** · "เดิม: <ค่าเดิม>" · ปุ่ม "คืนค่าเดิม" · ท้ายฟอร์ม "แก้ไข n ช่อง" เปิดรายการ เดิม → ใหม่ พร้อมปุ่ม "ไปที่ช่อง" · แผนกที่ระบบปรับให้ตรงกับผู้ถือครองเอง "ปรับตามผู้ถือครอง" | เปลี่ยนแล้ว · ย้อนกลับ · Reset |
| แผนกของทรัพย์สินบุคคลหรือ Stock ที่มีผู้ถือครอง (ฟอร์มทรัพย์สินและโอนย้าย) | ช่องแผนกเลือกไม่ได้ อ่าน **ตามผู้ถือครอง: <แผนก>** · ใบส่งมอบยังเปิดอยู่และแผนกไม่ตรง "แผนกไม่ตรงกับผู้ถือครอง จะปรับเมื่อรับคืนหรือโอนย้าย" | — |
| หน้าแก้ไขทรัพย์สินที่มีใบส่งมอบยังเปิดอยู่ (ผู้ถือครอง ที่ตั้ง แผนก แก้ไม่ได้) | "ใบส่งมอบ <HO-…> ยังเปิดอยู่ ถ้าผู้ถือครองหรือที่ตั้งผิด ให้ยกเลิกใบส่งมอบแล้วส่งมอบใหม่ หรือรับคืน" · ลิงก์ **เปิดใบส่งมอบ** | "…หรือใช้โอนย้าย" (โอนย้ายไม่รับทรัพย์สินที่มีใบส่งมอบค้าง) |
| ปุ่มคัดลอกที่ตั้งประจำไปเป็นที่ตั้งปัจจุบันในฟอร์มทรัพย์สิน | **ใช้ที่ตั้งประจำ** | ใช้คลัง IT ตามที่ตั้งประจำ |
| ส่วนที่พับไว้ของฟอร์มทรัพย์สิน | การจัดซื้อและประกัน · เอกสารจัดซื้อ · รูปทรัพย์สิน (หน้าเพิ่ม "รูปแรกเข้าทรัพย์สิน") · รายละเอียดเฉพาะทรัพย์สิน · **หมายเหตุ** | ข้อมูลเพิ่มเติม (ชื่อส่วนเดิมที่รวมทุกอย่าง) · ข้อมูลอื่น ๆ และขั้นสูง (ไม่มีช่อง JSON ในฟอร์มแล้ว) |
| นับเอกสารจัดซื้อ | **ใบ** · "เลือกแล้ว n ใบ" · "ผูกไว้ n ใบ" · "รอบันทึก n ใบ" · "พบ n ใบ จากเอกสารกลาง N ใบ" · "+ เพิ่มอีกใบ" | ฉบับ (เมื่อนับเอกสารจัดซื้อ · "ฉบับสมบูรณ์" ในความหมายอื่นใช้ได้) |
| นับทรัพย์สินที่ผูกกับเอกสารจัดซื้อ | **เครื่อง** ในผลค้นหาและชิปของช่องค้นหาเอกสารจัดซื้อ: "ผูกกับ n เครื่อง: <ชื่อ 3 รายการแรก>" · ชิป "ผูกกับ n เครื่อง" · นับทรัพย์สินในทะเบียนและรายการอื่นใช้ "รายการ" ตามเดิม · "เครื่องนี้" ที่หมายถึงทรัพย์สินหลักในหน้าส่วนควบ (ไม่ใช่การนับ) ใช้ได้: "ส่วนควบของเครื่องนี้: n รายการ" · "เคยติดตั้งกับเครื่องนี้ · ถอดออก <วันที่>" | "ผูกแล้ว n ทรัพย์สิน" · "n เครื่อง" เมื่อนับส่วนควบ (ใช้ "n รายการ") |
| ปุ่มและการกระทำที่บันทึกการซ่อมทรัพย์สิน | **บันทึกซ่อม** · "ใบแจ้งซ่อม" (ชื่อเอกสาร) และสถานะของบันทึก "แจ้งซ่อม" ใช้ได้ | "แจ้งซ่อม" เป็นชื่อปุ่มหรือการกระทำ |
| ปุ่มบนชิปเอกสารจัดซื้อที่เลือกไว้ในฟอร์มทรัพย์สิน (เอาออกจากทรัพย์สินนี้ ไม่ลบเอกสาร) | **เอา <เลขที่> ออก** · หน้าแก้ไขเอาออกเมื่อบันทึก "จะเอาออกเมื่อบันทึก" ปุ่ม "เก็บไว้" · เอกสารที่ปิดใช้งานแล้วมีป้าย "ปิดใช้งาน" | "ลบเอกสารจัดซื้อ" สำหรับการเอาออกจากทรัพย์สิน |
| สองส่วนของเอกสารจัดซื้อในฟอร์มทรัพย์สิน และเมื่ออัปโหลดหลังบันทึกไม่สำเร็จ | **เลือกเอกสารที่มีอยู่** (ค้นหาเอกสารกลาง) · **อัปโหลดเอกสารใหม่** · ปุ่ม "+ เพิ่มอีกใบ" · เอกสารที่รอบันทึกปุ่ม "เอา <เลขที่> ออก" · รายการแก้ไข "เพิ่ม <ประเภท> <เลขที่>" / "เอา <ประเภท> <เลขที่> ออก" (ไม่มี "— →") · บรรทัดช่วย "เลือกเอกสารที่มีอยู่ หรืออัปโหลดเอกสารใหม่ …" · หน้าแก้ไขหลังอัปโหลดไม่สำเร็จ "เอกสารจัดซื้อบางใบยังไม่ได้บันทึก" | "เลือกเอกสารกลางที่มีอยู่" · "สร้างเอกสารกลางใหม่" · "เพิ่มเอกสารเข้าคิวบันทึก" |
| เอกสารจัดซื้อในหน้าเพิ่มเป็นชุด | ส่วน **เอกสารจัดซื้อ** มี "เลือกเอกสารที่มีอยู่" และ "อัปโหลดเอกสารใหม่" (ไม่มี "+ เพิ่มอีกใบ") · "เอกสารที่เลือกและใบที่อัปโหลดจะผูกกับทรัพย์สินทุกรายการในชุดนี้ อัปโหลดได้ชุดละ 1 ใบ" · แนบเกิน "ชุดนี้แนบไฟล์เอกสารจัดซื้อได้ 1 ไฟล์" | "ผูกแล้ว n ทรัพย์สิน" (กล่องเลือกแบบเดิม) |
| ผู้ขายของเอกสารจัดซื้อที่อัปโหลดในฟอร์มทรัพย์สินและหน้าเพิ่มเป็นชุด | **ตามทรัพย์สิน** (ค่าเริ่มต้น ใช้ผู้ขายของทรัพย์สินหรือของชุด) · **ไม่ระบุผู้ขาย** (บันทึกโดยไม่มีผู้ขาย) · หรือเลือกผู้ขาย · เอกสารที่รอบันทึกแสดงผู้ขายที่จะบันทึกจริง | ตัวเลือกว่าง "เลือกผู้ขาย" ในช่องนี้ (ดูเหมือนไม่มีผู้ขาย แต่เดิมบันทึกเป็นผู้ขายของทรัพย์สิน) |
| หน้านำเข้าและส่งออกทรัพย์สิน (เมนู "นำเข้า/ส่งออก") | ชื่อหน้า **นำเข้า / ส่งออกทรัพย์สิน** (หน้านี้นำเข้าเป็นหลัก จึงต่างจากเมนูที่หัวหน้าทะเบียน) · การ์ด "นำเข้าทรัพย์สินจาก Excel" ขั้น แม่แบบ · อัปโหลด · ตรวจสอบ · นำเข้า · เสร็จสิ้น · การ์ด "ส่งออก" · "รอบนำเข้า <เลขรอบ>" · ไฟล์ที่เลือก "<ขนาด> · <n> แถว · ตรวจเมื่อ <วันที่>" | นำเข้าทรัพย์สินแบบ Wizard · ตัวช่วยนำเข้า · อัปโหลดเมื่อ (หน้านี้ไม่เก็บไฟล์) |
| ปัญหาของแถวในไฟล์นำเข้า | บรรทัดแรก "<ชื่อช่อง>: <ปัญหา>" · บรรทัดที่สอง **ค่าในไฟล์: <ค่า>** · ค่าที่ทรัพย์สินอื่นใช้อยู่ต่อท้าย " · **ใช้อยู่กับ** <รหัสทรัพย์สิน>" (ลิงก์ไปทรัพย์สินนั้น) · ทรัพย์สินที่ปิดใช้งาน "ใช้อยู่กับ <รหัสทรัพย์สิน> ที่ปิดใช้งานแล้ว" · ซ้ำในไฟล์เดียวกัน "ซ้ำกับแถว <n> ในไฟล์" · ในสรุปปัญหาที่พบซ้ำ "**ซ้ำกับแถวอื่นในไฟล์**" (ไม่ระบุแถว เพราะแต่ละกลุ่มซ้ำกับคนละแถว) · เซลล์ที่เป็นค่าผิดพลาดของสูตร (#N/A, #REF! …) "**เป็นค่าผิดพลาดจากสูตร Excel**" | ข้อความ error ภาษาอังกฤษ · "Branch Code ไม่อยู่ภายใต้ Company Code" |
| ปุ่มเลือกไฟล์ใหม่หลังแก้แถวที่มีข้อผิดพลาดในไฟล์นำเข้า | **อัปโหลดไฟล์ที่แก้แล้ว** · ยืนยัน "ยืนยันนำเข้า <n> รายการ" · หลังนำเข้า "นำเข้าไฟล์ใหม่" | อัปโหลดใหม่ (ไม่บอกว่าแก้แล้ว) |
| ส่งออกทั้งหมดในหน้านำเข้า / ส่งออก | "ส่งออกทั้งหมด (Excel)" · "<n> รายการ · **ไม่ใช้ตัวกรอง**" · เกินเพดาน "· ไฟล์มี <max> รายการที่เพิ่มล่าสุด" · ลิงก์ "ส่งออกตามตัวกรองในทะเบียน" | ตามสิทธิ์ · ตามสิทธิ์การเข้าถึง (ไฟล์ไม่ได้กรองตามสิทธิ์) · เลือกตัวกรองในทะเบียนแล้วส่งออก |

### 2.3 คงไว้

- ชื่อเฉพาะและคำที่พนักงานใช้อยู่แล้ว: LDAP · AD · QR · PDF · Excel · CSV · URL · API · Serial · License (เขียนแบบนี้ทุกที่ ไม่ใช้ "ไลเซนส์") · PM (หัวข้อเขียนเต็ม "บำรุงรักษาตามรอบ (PM)")
- หน้าผู้ดูแลระบบ (ตั้งค่า LDAP · Integration API · บันทึกระบบ) ใช้ศัพท์เทคนิคได้ เช่น Token · Client ID · JSON — แก้เฉพาะจุดที่มีคำไทยใช้ทั่วไป (เช่น ตัวกรอง ตัวอย่าง)
- ภาษาอังกฤษ (`messages/en.json`): ให้ key ตรงกับไทยเสมอ และแก้คำในความหมายเดียวกัน (Finding → Discrepancy · Review → Decision) ไม่ขัดเกลาทั้งไฟล์

## ใช้อย่างไร

- เขียนข้อความไทยใหม่ใช้คำในตารางเสมอ · `tests/thai-glossary.test.ts` ตรวจคำเลิกใช้ในทุกหมวดของ `messages/th.json`
- แก้ไฟล์ข้อความด้วย `node scripts/messages-edit.mjs <changes.json>` (รูปแบบไฟล์อยู่ในหัวสคริปต์) ไม่แก้ JSON ด้วยมือทั้งไฟล์
- ข้อยกเว้นเฉพาะ key ใส่ใน `keyExceptions` ของ test พร้อมเหตุผล
- ปีในหน้าไทยเป็น พ.ศ. (`src/lib/display-year.ts`) ยกเว้นรหัสที่มีปีในตัว
- error จากเซิร์ฟเวอร์แปลที่ `src/lib/api-error-catalog.ts` (เพิ่ม error ใหม่ใน API ต้องเพิ่มคำแปลด้วย test จึงจะผ่าน) · หน้าจอแสดงคำไทยก่อนและข้อความเดิมเป็นบรรทัดเล็กใต้ (`useApiError` / `ApiErrorText`)
- error ที่ไม่ได้ตั้งใจโยน (ฐานข้อมูล ไฟล์ บั๊ก) ไม่ส่งข้อความจริงให้ผู้ใช้ — ได้ "Unexpected error · ref xxxxxxxx" และ log ฝั่งเซิร์ฟเวอร์มี ref เดียวกัน (`src/lib/api-error-exposure.ts`) · ข้อความที่ตั้งใจให้ผู้ใช้เห็นต้องโยนเป็น `Error` ไม่ใช่ `TypeError`/`RangeError`
- รหัสสถานะจากฐานข้อมูล (เช่น `scanned`, `reviewed`) แสดงผ่านคำแปลเสมอ (`src/lib/audit-item-status-labels.ts`) · รหัสที่ยังไม่มีคำแปลแสดงตามจริง ไม่ซ่อน
