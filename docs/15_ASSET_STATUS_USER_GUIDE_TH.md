# คู่มือสถานะทรัพย์สินสำหรับผู้ใช้งาน

เอกสารนี้อธิบายความหมายของสถานะทรัพย์สิน สถานะที่สามารถดำเนินการต่อได้ และวิธีนำทรัพย์สินกลับสู่สถานะก่อนหน้าอย่างถูกต้อง

ดูแผนภาพและขั้นตอนแยกตามงานได้ที่ [Workflow สถานะทรัพย์สิน](./16_ASSET_STATUS_WORKFLOW_TH.md)

> สถานะทรัพย์สินต้องเปลี่ยนผ่านเมนูงานที่เกี่ยวข้อง เช่น เบิก รับคืน โอน ซ่อม หรือตัดจำหน่าย ไม่ควรแก้สถานะโดยตรงเพื่อข้ามขั้นตอนการทำงาน

## สถานะ กับ สภาพ ต่างกันอย่างไร

- **สถานะ** บอกขั้นตอนงาน เช่น พร้อมใช้งาน, ใช้งานอยู่, รอซ่อม, อยู่ระหว่างซ่อม หรือรอตัดจำหน่าย
- **สภาพ** บอกสภาพทางกายภาพที่ตรวจพบ ได้แก่ ยังไม่ประเมิน (`Not Assessed`), ใหม่, ดี, พอใช้, ชำรุด, ใช้งานไม่ได้ และซาก
- การเลือกสภาพ “ชำรุด” จะไม่ส่งซ่อมให้อัตโนมัติ ต้องกด **บันทึกซ่อม** ที่หน้าทรัพย์สิน (ดู [บันทึกซ่อมทำยังไง](./17_REPAIR_RECORD_GUIDE_TH.md))
- ค่าเดิม `Excellent` และ `Poor` ยังอ่านได้ในข้อมูลเก่า แต่ไม่ควรเลือกสำหรับรายการใหม่

## รายการรอตรวจสอบ

เปิดที่ **ผู้ดูแลระบบ > คุณภาพข้อมูล > รายการรอตรวจสอบสถานะและสภาพทรัพย์สิน** แล้วกด **สแกนรายการใหม่** ระบบจะตรวจหาข้อมูลที่ไม่สอดคล้องกัน แต่จะไม่เปลี่ยนสถานะหรือสภาพของทรัพย์สินโดยอัตโนมัติ

1. เปิดเลขทรัพย์สินและตรวจเอกสารหรือ workflow ที่เกี่ยวข้องก่อน
2. หากต้องแก้ ให้เลือก **แก้ไข** เลือกเฉพาะสถานะหรือสภาพที่ระบบอนุญาต และระบุเหตุผลอย่างน้อย 10 ตัวอักษร
3. หากข้อมูลเดิมถูกต้อง ให้เลือก **ยกเว้น** พร้อมบันทึกเหตุผล ระบบจะไม่แก้ทรัพย์สิน
4. หากระบบแจ้งว่าข้อมูลเปลี่ยนแล้ว ให้สแกนใหม่และตรวจสอบ snapshot ล่าสุด ห้ามฝืนใช้ข้อมูลหน้าจอเดิม

ผู้ใช้ที่มีสิทธิ์ดูการตั้งค่าจะเปิดดูรายการได้ ส่วนการสแกน แก้ไข และยกเว้น ต้องมีสิทธิ์แก้ไขการตั้งค่า การแก้ไขที่สำเร็จจะมีทั้งประวัติการเคลื่อนไหวและประวัติระบบสำหรับตรวจสอบย้อนหลัง

## สถานะและการดำเนินการต่อ

| สถานะ | ความหมาย | สถานะถัดไปที่ใช้ตามปกติ | วิธีคืนหรือย้อนสถานะ |
|---|---|---|---|
| ร่าง (`Draft`) | ข้อมูลทรัพย์สินยังอยู่ระหว่างจัดเตรียม | พร้อมใช้งาน | ตรวจสอบข้อมูลที่จำเป็นให้ครบก่อนเปิดใช้งาน |
| พร้อมใช้งาน (`Ready`) | ทรัพย์สินพร้อมสำหรับการเบิก โอน หรือนำไปใช้งาน | ใช้งานอยู่, ถูกเบิก, อยู่ระหว่างซ่อม, รอตัดจำหน่าย | เป็นสถานะหลักที่ใช้เมื่อทรัพย์สินกลับมาพร้อมใช้งาน |
| ใช้งานอยู่ (`In Use`) | ทรัพย์สินถูกมอบหมายใช้งานประจำหรือมีบุคคลเป็นผู้ถือครอง | พร้อมใช้งานเมื่อรับคืนปกติ, ใช้งานอยู่เมื่อโอนให้ผู้ถือครองคนใหม่, อยู่ระหว่างซ่อม, รอตัดจำหน่าย | รายการใช้งานประจำให้รับคืนผ่านหน้า Check-in ไม่ต้องแก้สถานะเอง |
| จอง (`Reserved`) | สถานะเก่าแบบควบคุมสำหรับทรัพย์สินที่เคยถูกกันไว้ | พร้อมใช้งาน, ใช้งานอยู่, หาไม่พบ หรือสูญหาย ผ่านรายการรอตรวจสอบ | ไม่มี workflow การจองปกติ ให้ผู้ดูแลตรวจข้อเท็จจริงและแก้ผ่านรายการรอตรวจสอบ |
| ถูกเบิก (`Checked Out`) | ทรัพย์สินถูกเบิกใช้งานชั่วคราวให้บุคคล แผนก สถานที่ หรือทรัพย์สินหลัก | พร้อมใช้งาน, อยู่ระหว่างซ่อม (เลือก **ส่งซ่อม** ตอนรับคืน), รอตัดจำหน่าย | ทำรายการรับคืน (`Check-in`) และเลือกผลหลังรับคืน |
| อยู่ระหว่างโอนย้าย (`In Transit`) | สถานะเก่าแบบควบคุมสำหรับการขนส่งหรือย้ายพื้นที่ที่ยังไม่สรุป | พร้อมใช้งาน, ใช้งานอยู่, หาไม่พบ หรือสูญหาย ผ่านรายการรอตรวจสอบ | ไม่มี workflow รับปลายทางปกติ ให้ผู้ดูแลตรวจข้อเท็จจริงและแก้ผ่านรายการรอตรวจสอบ |
| รอซ่อม (`Pending Repair`) | สถานะจากขั้นตอนซ่อมแบบเดิม งานใหม่ไม่ใช้แล้ว (เก็บไว้อ่านประวัติ) | อยู่ระหว่างซ่อม, ใช้งานอยู่ / พร้อมใช้งาน, รอตัดจำหน่าย | กด **บันทึกซ่อม** ให้ชิ้นนั้น (หน้าซ่อมบำรุงมีกล่อง "ทรัพย์สินค้างสถานะซ่อมแต่ไม่มีบันทึก") หรือให้ผู้มีสิทธิ์แก้กลับเป็นพร้อมใช้งานพร้อมเหตุผลถ้าไม่ต้องซ่อม |
| อยู่ระหว่างซ่อม (`Under Maintenance`) | ทรัพย์สินถูกส่งซ่อมและมีบันทึกซ่อมที่ยังไม่เสร็จ | ใช้งานอยู่เมื่อยังมีผู้ถือครอง, พร้อมใช้งานเมื่อไม่มีผู้ถือครอง, หรือรอตัดจำหน่าย | เปิดบันทึกซ่อมแล้วกด **ซ่อมเสร็จ** และเลือกผลการซ่อม ระบบเลือกสถานะให้ตามผู้ถือครอง หรือ **ยกเลิกบันทึก** ถ้าบันทึกผิด |
| อยู่ระหว่างตรวจสอบ (`Under Inspection`) | สถานะใช้งานจริงสำหรับทรัพย์สินที่กำลังตรวจสอบตำแหน่ง ผู้ถือครอง สภาพ หรือข้อมูล | ปัจจุบันออกจากสถานะนี้ได้โดยแก้กลับเป็นพร้อมใช้งานแบบควบคุม | บันทึกผลตรวจและเหตุผล แก้กลับเป็นพร้อมใช้งาน แล้วจึงทำรายการโอน ซ่อม หรือตัดจำหน่ายตามข้อเท็จจริง |
| สูญหาย (`Lost`) | มีหลักฐานหรือข้อสรุปว่าทรัพย์สินสูญหาย | ไม่มีสถานะถัดไปในการใช้งานปกติ | เมื่อพบทรัพย์สินและยืนยันว่าใช้งานได้ ให้ผู้มีสิทธิ์แก้กลับเป็นพร้อมใช้งานพร้อมเหตุผล |
| หาไม่พบ (`Missing`) | ยังไม่พบทรัพย์สินระหว่างตรวจสอบหรือตรวจนับ | ไม่มีสถานะถัดไปในการใช้งานปกติ | เมื่อพบทรัพย์สินและตรวจสอบเรียบร้อย ให้ผู้มีสิทธิ์แก้กลับเป็นพร้อมใช้งานพร้อมเหตุผล |
| รอตัดจำหน่าย (`Pending Disposal`) | ทรัพย์สินรอดำเนินการตัดจำหน่ายหรือปลดระวาง | ตัดจำหน่ายแล้ว หรือปลดระวาง | หากคำขอถูกปฏิเสธ ระบบคืนสถานะเดิมที่บันทึกไว้ก่อนสร้างคำขอ ไม่ได้บังคับกลับเป็นพร้อมใช้งานเสมอ |
| ตัดจำหน่ายแล้ว (`Disposed`) | การตัดจำหน่ายเสร็จสมบูรณ์และปิดวงจรทรัพย์สินแล้ว | ไม่มี | แก้กลับเป็นพร้อมใช้งานได้เฉพาะกรณีบันทึกผิดและต้องมีเหตุผลประกอบ |
| ปลดระวาง (`Retired`) | เลิกใช้งานทรัพย์สินอย่างถาวร | ไม่มี | แก้กลับเป็นพร้อมใช้งานได้เฉพาะกรณีบันทึกผิดและต้องมีเหตุผลประกอบ |

## ขั้นตอนหลักที่ใช้บ่อย

### การอ่านสถานะงานซ่อมบนแดชบอร์ด

ภาพรวมสถานะบนแดชบอร์ดนับจากสถานะปัจจุบันของทรัพย์สินโดยตรง:

- **รอซ่อม (`Pending Repair`)** สถานะจากขั้นตอนเดิม ถ้ายังมีตัวเลข แปลว่ามีทรัพย์สินค้างที่ต้องบันทึกซ่อมให้
- **อยู่ระหว่างซ่อม (`Under Maintenance`)** ทรัพย์สินที่ส่งซ่อมอยู่

เมื่อกดตัวเลขของแต่ละสถานะ ระบบจะเปิดทะเบียนทรัพย์สินและกรองด้วยสถานะนั้นโดยตรง ส่วนการ์ด **ยังซ่อมไม่เสร็จ** นับจากบันทึกซ่อมที่ยังไม่กดซ่อมเสร็จ และเปิดหน้าซ่อมบำรุงที่กรองไว้แล้ว ตัวเลขสองแบบนี้อาจไม่เท่ากันถ้ามีทรัพย์สินค้างสถานะซ่อมแต่ไม่มีบันทึก

### ส่งมอบทรัพย์สิน

```text
พร้อมใช้งาน
├─ มอบหมายใช้งานประจำให้พนักงาน → ใช้งานอยู่
└─ เบิกใช้งานชั่วคราว             → ถูกเบิก
```

## การส่งมอบแบบใช้งานประจำและชั่วคราว

- `มอบหมายใช้งานประจำ`: ใช้เมื่อส่งให้พนักงานถือครองต่อเนื่อง ระบบเปลี่ยนเป็น `ใช้งานอยู่` และไม่ให้ใส่กำหนดคืน
- `เบิกใช้งานชั่วคราว`: ใช้เมื่อต้องคืน ระบบเปลี่ยนเป็น `ถูกเบิก` และบังคับกำหนดคืน
- ตอนรับคืน ระบบแสดง `ลักษณะการถือครอง` เป็น `ใช้งานประจำ` หรือ `เบิกชั่วคราว` เพื่อยืนยันบริบท ไม่ใช่ให้แก้ประเภท
- ถ้าระบบแจ้งว่าประเภทหายหรือสถานะไม่ตรง ให้ผู้ดูแลตรวจในรายการรอตรวจสอบ ห้ามเปลี่ยนสถานะเองเพื่อทำรายการต่อ

ใช้เมื่อต้องการมีรายการเบิก กำหนดวันส่งมอบ วันคาดว่าจะคืน และหลักฐานผู้รับ

### โอนทรัพย์สินให้บุคคล

```text
พร้อมใช้งาน
→ โอนให้ผู้ถือครอง
→ ใช้งานอยู่
```

เมื่อเลือกผู้ถือครองปลายทาง ระบบจะเปลี่ยนสถานะเป็น **ใช้งานอยู่** โดยอัตโนมัติ ผู้ทำรายการไม่ต้องเลือกสถานะแยกอีกครั้ง

หากย้ายเฉพาะสถานที่หรือแผนกโดยไม่ได้เลือกผู้ถือครองปลายทาง ระบบจะคงสถานะเดิมของทรัพย์สิน

### รับคืนทรัพย์สิน

```text
ใช้งานอยู่ (ใช้งานประจำ) ─┐
                            ├─ รับคืนและตรวจสอบสภาพ → พร้อมใช้งาน / ส่งซ่อม (อยู่ระหว่างซ่อม) / รอตัดจำหน่าย
ถูกเบิก (เบิกชั่วคราว) ────┘
```

การรับคืนปกติต้องมีรายการเบิกที่ยังเปิดอยู่ หากเป็นข้อมูลเก่าที่มีผู้ถือครองแต่ไม่มีรายการเบิก สถานะต้องเป็น **พร้อมใช้งาน** หรือ **ใช้งานอยู่** และต้องไม่มีบันทึกซ่อมที่ยังไม่เสร็จ ระบบจึงจะแสดงในส่วน **ข้อมูลเก่า** เพื่อสร้างรายการส่งมอบย้อนหลังที่ตรวจสอบได้ก่อน แล้วจึงใช้ขั้นตอนรับคืนปกติ

หากบันทึกซ่อมแบบยังไม่เสร็จไว้ผิด ให้เปิดบันทึกนั้นแล้วกด **ยกเลิกบันทึก** (เหตุผลไม่บังคับ) ระบบจะคืนเป็น **ใช้งานอยู่** เมื่อยังมีผู้ถือครองหรือรายการส่งมอบที่ยังเปิด หรือ **พร้อมใช้งาน** เมื่อไม่มีผู้ถือครอง จากนั้นจึงทำรายการรับคืนย้อนหลังได้ บันทึกที่ซ่อมเสร็จแล้วยกเลิกไม่ได้ ให้ใช้ **แก้ไขรายละเอียด** แทน

### ยกเลิกรายการส่งมอบ รับคืน หรือโอนย้ายที่บันทึกผิด

ใช้เมื่อลงรายการล่าสุดผิด เช่น เลือกผู้รับ สถานที่ หรือผลการรับคืนไม่ถูกต้อง ไม่ควรแก้สถานะหรือข้อมูลผู้ถือครองโดยตรงเพื่อกลบรายการเดิม

1. เปิดหน้ารายละเอียดทรัพย์สิน แล้วเปิดเมนู **การทำงานเพิ่มเติม** หรือเปิดเอกสารส่งมอบ รับคืน หรือโอนย้ายรายการนั้น
2. เลือก **ยกเลิกรายการ** ระบบจะแสดงผู้ทำรายการเดิม สถานะปัจจุบัน สถานะที่จะคืนกลับ และจำนวนส่วนควบที่ได้รับผลกระทบ
3. ตรวจข้อมูลให้ครบ แล้วระบุเหตุผลอย่างน้อย 5 ตัวอักษรก่อนยืนยัน
4. เมื่อสำเร็จ เอกสารเดิมจะคงอยู่และแสดง `VOID / ยกเลิกแล้ว` พร้อมผู้ยกเลิก วันเวลา และเหตุผล ระบบจะบันทึก Movement และ System Log เพิ่มเติม

ผลของการยกเลิกแต่ละรายการ:

- **ยกเลิกส่งมอบ (Check-out):** คืนข้อมูลก่อนส่งมอบ เช่น สถานะ ผู้ถือครอง และสถานที่ ตาม Snapshot ที่บันทึกไว้
- **ยกเลิกรับคืน (Check-in):** คืนทรัพย์สินกลับสู่ข้อมูลก่อนรับคืน และเปิดรายการส่งมอบเดิมให้สามารถรับคืนใหม่อย่างถูกต้อง เอกสารรับคืนที่ยกเลิกยังเก็บไว้เป็นประวัติ
- **ยกเลิกโอนย้าย (Transfer):** คืนสถานที่ ผู้ถือครอง แผนก สถานะ และส่วนควบตามข้อมูลก่อนโอนย้าย

ระบบจะไม่คืนค่าอัตโนมัติเมื่อมีรายการใหม่กว่า ข้อมูลทรัพย์สินหรือส่วนควบเปลี่ยนไป มีงานถัดไปอ้างอิงอยู่ หรือเป็นรายการเก่าที่ไม่มี Snapshot ในกรณีนี้ข้อมูลปัจจุบันจะไม่ถูกเปลี่ยนบางส่วน และระบบจะสร้าง **รายการรอตรวจสอบ** ให้ผู้ดูแลตรวจข้อเท็จจริง ห้ามใช้ Status Correction เพื่อข้ามรายการรอตรวจสอบดังกล่าว

### ส่งซ่อม

```text
ซ่อมเสร็จแล้ว (ใช้งานได้)       → สถานะเดิม ไม่เปลี่ยน
ยังซ่อมไม่เสร็จ                 → อยู่ระหว่างซ่อม → กด "ซ่อมเสร็จ" → ใช้งานอยู่ (มีผู้ถือครอง) / พร้อมใช้งาน
ซ่อมไม่ได้ เสนอจำหน่าย          → รอตัดจำหน่าย
รับคืนแล้วเลือก "ส่งซ่อม"        → อยู่ระหว่างซ่อม (ระบบสร้างบันทึกซ่อมให้)
```

ขั้นตอนทีละข้อดูที่ [บันทึกซ่อมทำยังไง](./17_REPAIR_RECORD_GUIDE_TH.md) · ห้ามเปลี่ยนทรัพย์สินที่อยู่ระหว่างซ่อมเป็นใช้งานอยู่เอง ให้กด **ซ่อมเสร็จ** ที่บันทึกซ่อม · ของที่ถูกเบิกชั่วคราว (`Checked Out`) ต้องรับคืนก่อนจึงบันทึกแบบยังไม่เสร็จได้ · ของที่ยังมีรายการส่งมอบค้าง (ทั้งเบิกชั่วคราวและใช้งานประจำ) ต้องรับคืนก่อนจึงเลือก **ซ่อมไม่ได้** ได้

### ตัดจำหน่ายหรือปลดระวาง

```text
พร้อมใช้งาน / ใช้งานอยู่ / อยู่ระหว่างซ่อม / ทรัพย์สินที่รับคืน
→ รอตัดจำหน่าย
→ ตัดจำหน่ายแล้ว / ปลดระวาง
```

สถานะ **ตัดจำหน่ายแล้ว** และ **ปลดระวาง** เป็นสถานะปิด ไม่สามารถนำทรัพย์สินไปเบิกหรือโอนตามปกติได้

หากคำขอตัดจำหน่ายถูกปฏิเสธ ระบบจะคืนสถานะที่บันทึกไว้ก่อนสร้างคำขอ เช่น **พร้อมใช้งาน** หรือ **ใช้งานอยู่** รายการเก่าที่ไม่มีสถานะเดิมจะถูกส่งให้ผู้ดูแลตรวจสอบแทนการคาดเดาสถานะ

### พบทรัพย์สินที่เคยสูญหายหรือหาไม่พบ

```text
สูญหาย / หาไม่พบ
→ ตรวจสอบทรัพย์สินและยืนยันข้อมูล
→ แก้ไขสถานะเป็นพร้อมใช้งาน
```

การแก้ไขต้องดำเนินการโดยผู้มีสิทธิ์ พร้อมระบุเหตุผลเพื่อเก็บประวัติการเปลี่ยนแปลง

### ทรัพย์สินอยู่ระหว่างตรวจสอบ

`Under Inspection` ยังเป็นสถานะที่ระบบใช้งาน ไม่ใช่สถานะข้อมูลเก่า ระหว่างตรวจสอบระบบจะไม่อนุญาตให้เบิกหรือโอนให้บุคคลตามปกติ และผู้ใช้ไม่ควรเปลี่ยนสถานะผ่านหน้าแก้ไขทรัพย์สินทั่วไป

- ตรวจแล้วพร้อมใช้: แก้สถานะกลับเป็น **พร้อมใช้งาน** พร้อมเหตุผล
- ยืนยันผู้ถือครองเดิมและต้องการใช้งานต่อ: แก้กลับเป็น **พร้อมใช้งาน** แล้วทำรายการโอนให้บุคคล ระบบจะตั้งเป็น **ใช้งานอยู่** อัตโนมัติ
- พบความเสียหาย: บันทึกผลตรวจ แก้กลับเป็น **พร้อมใช้งาน** แบบควบคุม แล้วกด **บันทึกซ่อม** (ถ้ายังไม่เสร็จ ทรัพย์สินจะเป็น **อยู่ระหว่างซ่อม**)
- แนะนำตัดจำหน่าย: บันทึกผลตรวจ แก้กลับเป็น **พร้อมใช้งาน** แบบควบคุม แล้วเปิดคำขอตัดจำหน่ายเพื่อเข้าสู่ **รอตัดจำหน่าย**
- ยืนยันว่าสูญหายหรือยังหาไม่พบ: บันทึก Finding และหลักฐานเพื่อสอบสวน ปัจจุบันการกดไม่พบในงานตรวจนับจะไม่เปลี่ยนสถานะทรัพย์สินเป็น **สูญหาย** หรือ **หาไม่พบ** อัตโนมัติ

## ข้อควรทราบ

1. **สถานะ** และ **สภาพทรัพย์สิน** เป็นข้อมูลคนละส่วน
   - สถานะบอกว่าทรัพย์สินอยู่ในขั้นตอนใด เช่น พร้อมใช้งาน ถูกเบิก หรืออยู่ระหว่างซ่อม
   - สภาพบอกสภาพจริง เช่น ใหม่ ดี ชำรุด หรือเสียหาย
2. ทรัพย์สินสภาพเสียหายไม่ควรถูกกำหนดเป็นพร้อมใช้งานโดยไม่ผ่านการตรวจสอบหรือซ่อม
3. การรับคืนต้องเลือกผลหลังรับคืนตามสภาพจริง
4. การย้อนสถานะที่เกี่ยวกับการซ่อม สูญหาย หรือตัดจำหน่าย ต้องระบุเหตุผลและเก็บประวัติ
5. การยกเลิกรายการส่งมอบ รับคืน หรือโอนย้ายใช้ Snapshot ของรายการเดิม ไม่ใช่การเลือกสถานะใหม่ด้วยตนเอง
6. หากไม่แน่ใจว่าควรเลือกสถานะใด ให้หยุดรายการและสอบถามผู้ดูแลทรัพย์สินก่อนยืนยัน

## สรุปแบบย่อ

```text
ร่าง → พร้อมใช้งาน
พร้อมใช้งาน → มอบหมายใช้งานประจำให้พนักงาน → ใช้งานอยู่
พร้อมใช้งาน → เบิกใช้งานชั่วคราว → ถูกเบิก
ใช้งานอยู่ (ประจำ) / ถูกเบิก (ชั่วคราว) → รับคืน → พร้อมใช้งาน / ส่งซ่อม (อยู่ระหว่างซ่อม) / รอตัดจำหน่าย
รายการล่าสุดผิด → ยกเลิกรายการ → คืน Snapshot เดิมและเก็บเอกสารเป็น VOID
พร้อมใช้งาน / ใช้งานอยู่ → บันทึกซ่อม (ยังไม่เสร็จ) → อยู่ระหว่างซ่อม
อยู่ระหว่างซ่อม → ซ่อมเสร็จ → ใช้งานอยู่ตามผู้ถือครอง / พร้อมใช้งาน / รอตัดจำหน่าย
รอซ่อม (ข้อมูลเดิม) → บันทึกซ่อม → อยู่ระหว่างซ่อม / สถานะตามผู้ถือครอง / รอตัดจำหน่าย
อยู่ระหว่างตรวจสอบ → สรุปผลและแก้แบบควบคุม → พร้อมใช้งาน → โอน / ซ่อม / ตัดจำหน่ายตามข้อเท็จจริง
รอตัดจำหน่าย → ดำเนินการ → ตัดจำหน่ายแล้ว / ปลดระวาง
รอตัดจำหน่าย → คำขอถูกปฏิเสธ → สถานะเดิมที่ระบบบันทึกไว้
สูญหาย / หาไม่พบ → ตรวจพบและยืนยัน → พร้อมใช้งาน
```
